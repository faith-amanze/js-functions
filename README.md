# JavaScript Functions

A collection of JavaScript functions covering strings, arrays and math.

**Live demo:** https://codepen.io/editor/Faith-Amanze/pen/01a17713-1bf9-7f5b-aa19-61120fe0d402

## Functions

### String Manipulation
- `reverseString(str)`: reverses a string
- `countCharacters(str)`: counts the characters in a string
- `capitalizeWords(sentence)`: capitalizes the first letter of each word

### Arrays
- `findMax(arr)` and `findMin(arr)`: find the largest and smallest values
- `sumArray(arr)`: adds up all the elements
- `filterArray(arr, condition)`: keeps only the elements that meet a condition

### Math
- `factorial(n)`: calculates the factorial of a number
- `isPrime(n)`: checks whether a number is prime
- `fibonacci(terms)`: generates the Fibonacci sequence up to a given number of terms
